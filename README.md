# Русификатор Void Hunters от Luuke

Русификатор для ПК-версии Void Hunters. Установщик проверяет файлы игры, создаёт резервную копию и позволяет восстановить оригиналы. В приложении есть кнопка **«Запустить игру»**.

## Установка

1. Закройте игру и официальный лаунчер.
2. Скачайте ZIP из **Assets** нужного релиза и распакуйте его целиком.
3. Запустите `Luuke-Void-Hunters.exe`. Установщик ищет игру автоматически. Если папка не найдена, укажите её в **«Настройках»**.
4. Нажмите **«Установить перевод»**. Когда появится **«Перевод установлен»**, нажмите **«Запустить игру»**.

Кнопка **«Восстановить»** возвращает исходные файлы из резервной копии. Если после патча игры установщик сообщает о несовместимости, проверьте, есть ли выпуск для нового билда.
